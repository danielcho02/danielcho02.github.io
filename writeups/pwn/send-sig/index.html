Vulnerability & Code Analysis

따로 소스코드가 제공되어 있지 않으므로 IDA를 이용해 바이너리를 분석한다.

sub_4010B6()함수를 분석해보자.

buf의 크기는 8byte이지만 읽는 버퍼의 크기가 0x400이므로 stack buffer overflow가 가능하다. 다만 ROPchain을 구성하기 위해서는 버퍼의 크기가 작으므로 SROP를 사용해서 셸을 딸 수 있다.

Exploit / Solver Strategy

기존에 풀었던 srop문제와 같은 방식으로 익스플로잇 설계를 진행한다. 다만 srop와 달리 주어진 gadget이 없으므로 ROPgadget을 사용하여 필요한 가젯의 주소를 얻는다.

따라서 이를 이용해서 1차 sigreturn syscall을 호출하는 SigreturnFrame()을 만든다.

이후에 execve syscall을 .bss영역에 /bin/sh의 주소와 2차 payload로 구성한다.
