목표: Canary 보호 기법 우회, get_shell 함수 실행

분석 및 설계

  • checksec 확인

  • Input
    box를 A로 채운 후, P 기능을 이용해 index를 하나씩 증가시키며 값을 확인
    처음에는 box 범위(0~63)까지는 0x41이 나오고, 그 이후부터는 0x00이 나타남
    단순히 0x00이 나온다고 canary라고 판단하지 않고,
    index를 계속 증가시키면서 00 xx xx xx 형태의 패턴 발견
    여러 index를 확인한 결과, 해당 패턴이 나타나는 지점을 canary 시작 위치로 판단

  • pwndbg 이용 분석

name이 주소 [ebp-0x48], box의 주소 [ebp-0x88] 확인

Exploit

box의 idx를 0x80 ~ 0x84로 설정, ebp-0x8 ~ ebp-0x4사이 Canary 4byte (32bit arch)

get_shell의 주소 p32(0x80486b9) payload로 덮기
