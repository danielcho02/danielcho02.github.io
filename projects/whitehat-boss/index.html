A team project for the second round of KISA WhiteHat School 4th. Instead of one large model, several small LLMs each take one stage:

  • Find candidate spots (Scout), review them (Auditor), filter them (Gate, Critic)
  • Build an input that actually crashes the target (PoV) and verify the result (Oracle)
  • Runs CyberGym tasks through stages 0 to 9; a dev_fake profile checks the plumbing without a GPU

Architecture and usage are in the repository.
